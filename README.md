# Lost and Found Management System

## About the Project
The Lost and Found Management System is a console-based application developed using C++. It helps students report lost and found items in college and search for previously reported items.

## Features
- Report lost or found items.
- Generate a unique ID for every report.
- Display all reported items.
- Search for items by name.
- Validate user input.
- Store records using file handling.
- Load previously saved records when the program starts.

- C++

## How to Run
1. Open the project folder in VS Code.
2. Compile `main.cpp` using a C++ compiler.
3. Run the generated executable.

## Files
- `main.cpp` – Main source code.
- `README.md` – Project documentation.
- `lost_found.txt` – Automatically created to store records when the program runs.
